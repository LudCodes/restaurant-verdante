# Verdanté — Website Institucional

Website institucional desenvolvido para a **Verdanté**, com uma identidade visual elegante e moderna, proporcionando uma experiência digital intuitiva e responsiva.

O projeto foi desenvolvido com foco em desenvolvimento Front-end, organização de código, responsividade e experiência do usuário (UX).

## ✨ Funcionalidades

- Página inicial com apresentação da marca.
- Layout moderno e responsivo.
- Navegação intuitiva entre as seções.
- Cardápio digital.
- Seção de apresentação do restaurante.
- Formulário de reservas.
- Animações e elementos visuais interativos.

## 🛠️ Tecnologias utilizadas

- **Next.js** — Framework React para desenvolvimento web.
- **React** — Construção de interfaces.
- **TypeScript** — Tipagem estática e maior segurança no código.
- **Tailwind CSS** — Estilização e construção de interfaces.
- **CSS** — Personalização visual e responsividade.

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js
- pnpm

### Instalação

1. Clone o repositório:

```bash
git clone https://github.com/LudCodes/restaurant-verdante.git
```

2. Entre na pasta do projeto:

```bash
cd website-verdante
```

3. Instale as dependências:

```bash
pnpm install
```

4. Inicie o servidor de desenvolvimento:

```bash
pnpm dev
```

5. Acesse no navegador:

```text
http://localhost:3000
```

### Build de produção

Para gerar a versão de produção:

```bash
pnpm build
```
